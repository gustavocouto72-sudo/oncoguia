# Ficha MBE — Dano e estudos observacionais
> Base: Guyatt 3ª ed. (cap. 4, 10, 14). Para verificar regimes cuja evidência-chave é de segurança/observacional.

## PICO de dano
P (população + vulnerabilidades) · **I = exposição** (droga/fator) · C (não exposto/exposto diferente) · O (evento adverso relevante).

## Desenho e confiança inicial
- **Coorte** — expostos vs não expostos, prospectivo; ideal para temporalidade. Medida: **RR**.
- **Caso-controle** — parte do desfecho, busca exposição retrospectiva. Medida: **OR**.
- RCT de dano costuma ser antiético → observacional é a melhor evidência disponível (inicia **baixa** no GRADE).

## Risco de viés (validade interna) — checklist
- Similaridade prognóstica dos grupos (Tabela 1 basal; desequilíbrio = confundidor).
- Cegamento do avaliador do desfecho quanto à exposição (viés de aferição em desfechos subjetivos).
- Completude e duração do seguimento (dano precisa de tempo para se manifestar; contabilizar perdas).

## Resultados
- **Magnitude** — RR/OR longe de 1,0 = associação forte.
- **Precisão** — IC estreito; largo cruzando limiares opostos = impreciso.
- **Gradiente dose-resposta** — reforça causalidade e plausibilidade biológica.

## Elevação (observacional)
+1 se RR >2 / <0,5; +2 se RR >5 / <0,2; +1 gradiente dose-resposta; +1 confusão residual oposta.

## Busca eficiente
Pirâmide 6-S: Sistemas → Sumários → Sinopses de síntese → Sínteses → Sinopses de estudo → Estudos primários. Usar PubMed Clinical Queries filtro **Harm** só quando os recursos sintetizados falharem.
